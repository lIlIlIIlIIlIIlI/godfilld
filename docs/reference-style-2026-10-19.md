# 공식 웹 화면 스타일 대조 — 2026-10-19

요청한 기준은 [한국어 공식 웹 클라이언트](https://godfield.net/?lang=ko)다. Chromium에서 직접 홈, 메뉴, 훈련 설정, CPU 전투, 비밀 결투의 독립 검사 방, 교전, 설정을 열고 DOM의 `getBoundingClientRect()`와 `getComputedStyle()`을 수집했다. 공식 공개 대전에는 참가하지 않았다. 이전의 화면 확장·자체 메뉴 배치를 이 측정값으로 교체했다.

## 확인한 값과 반영

좌표는 별도 표시가 없으면 해당 화면의 콘텐츠 영역 기준이다. PC 화면은 1080×720, 헤더 30, 본문 660, 푸터 30픽셀이며 body 여백은 8픽셀이다. 가로 1280픽셀 브라우저에서 앱의 좌표는 (100, 8)이다.

## 동작 확인과 범위

411개 자동 테스트와 TypeScript·Vite 운영 빌드를 통과했다. 브라우저에서는 홈 입력, 설정 열기·돌아가기, 세로 메뉴, 비밀번호 팝업, 교전 탭, 비공개 방 생성, 팀 선택, 봇 추가, 방장의 팀 섞기, 준비·시작, 전투, 9인 훈련, 390픽셀 세로 화면을 확인했다. PC 손패는 `clientWidth === scrollWidth === 736`, `clientHeight === scrollHeight === 205`로 불필요한 스크롤이 사라졌음을 확인했다.

이 작업은 화면 재현이다. 게임 엔진의 기존 독립 규칙, 신규 한국어 카드명, 실제 서버 인원, 난이도·종말 설정값은 그대로 사용한다. 원본의 세계 접속자 수나 랭킹을 표시하지 않는다. 설정은 원본의 색상·글꼴·언어 선택 배치를 적용하고 프로젝트의 이름·소리·애니메이션 설정을 제공한다. 진지 1:1 전투는 현재 친구와의 2인 방을 제공하며 원본의 랭크 매칭은 구현하지 않았다. 각 OS의 설치 글꼴에 따라 글자 렌더링이 달라질 수 있으므로 모든 픽셀의 완전 일치를 주장하지 않는다.

기존의 전투 읽기 시간(시작 2.2초, 피해 1.4초, 승천 1.8초, AI 기본 1.8초)과 세로 화면의 실제 게임 조작을 유지한다. 원본은 Android/iPhone 접속 시 앱 다운로드 화면을 제공하지만, 이 프로젝트는 기존 모바일 게임 화면을 유지한다.
