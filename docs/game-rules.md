# 별의 의회 규칙 v0.1

> 2026-10-19 추가 조사: [공식 공개 클라이언트·한국어 설명과 REA 근거](godfield-research-2026-10-19.md)를 확인하세요. 최대 인원은 9인으로 확장했습니다. 공식 JSON의 빛 방어 불가·수호신 25%와 이 프로젝트의 기존 어둠 방어 허용·30%를 구분합니다. 아래 기존 규칙은 인원 외에는 유지합니다.

이 규칙은 God Field에서 영감을 받은 독립 웹게임의 규칙입니다. 원본 공식 규칙서가 아닙니다. 모호한 수치는 `server/src/game/Rules.ts`의 설정입니다.

## 상태와 명령

`WAITING → NEXT_TURN → ATTACK_SELECTION → RESOLVING → DEFENSE_SELECTION / BUY_CONFIRMATION → TURN_END → NEXT_TURN`, 최종 `FINISHED`.

공격 큐, 질병 처리, 수호자 개입, 보충이 끝나기 전에는 다음 공격자를 뽑지 않습니다. 반사는 큐 선두, 반격·유언은 큐 후미입니다. 깊이24를 넘는 공격은 기록을 남기고 중단하며, 경기600턴 안전 한도는 명시적 무승부입니다. 사망자가 남긴 공격까지 처리한 다음 승패를 확정합니다.

모든 외부 명령은 행동 ID와 상태 버전을 갖습니다. 동일 사용자의 중복 행동과 오래된 버전은 거부합니다. 상태 전체의 복제본에 적용하고 검증·처리가 모두 성공하면 저장합니다. 저장 실패 시 클라이언트에 성공 상태를 보내지 않습니다. DB 방 단위 트랜잭션으로 동시에 들어온 입력을 직렬화합니다.

## 공격·방어·속성

기본 무기 한 장으로 시작하고, 확률0인 무기에 한해 추가 공격·배율·광역·속성 부여를 순서대로 연결합니다. MAGIC_FREE는 기적 바로 뒤에 놓아 해당 비용만 면제합니다. MP는 전체 조합의 실제 사용 순서대로 차감합니다. MAGICAL은 조합 비용을 처리한 후 남은 MP의 두 배 피해, 남은 MP0. 수호자가 생성한 MAGICAL은200 피해이며 주인 MP를 소비하지 않습니다.

속성 표는 분석 문서와 같습니다. LIGHT 방어는 FIRE/WATER/TREE/SOIL 공격을 방어합니다. LIGHT 공격은 기본 설정에서 DARK 방어로만 방어합니다. DARK 공격은 어떤 속성 방어든 사용할 수 있으나, 수호자 흡수 이후 HP에 피해가 있으면 즉사합니다. 일반 공격의 흡수·자해·재앙은 실제 HP 피해가 있을 때 처리합니다.

DFS를 여러 장 합산하고 합성된 방어 속성을 검사합니다. 섬광이면 비용 면제 카드도 포함하여 총1장 제한. REMOVE_ATTRIBUTE는 공격 속성을 무속성으로 바꾸고 후속 방어를 허용합니다. 특수 방어는 무기/기적 분류와 속성 조건을 검사합니다. REFLECT_ANY는 넓은 예외이며 반격에도 사용 가능합니다. 튕김은 자신을 포함한 살아 있는 임의 대상에게 방어 불가 공격을 보냅니다. 반사는 선행 일반 방어로 깎기 전의 원래 공격량을 돌려보내며 재방어 가능, 모든 연쇄는 깊이 제한을 받습니다.

반격 수치는 방어로 감소한 뒤의 공격량(수호자 흡수 전)을 기준으로 합니다. 187 화염 반격은 해당 수치·75% 적 전체, 190 대지 반격은2배, 193은본인 MP2배, 194는소지금 흡수. 재앙 반격은 각 카드의 attackExtra를 사용합니다. 일반 반격은 추가 방어가 제한되며 만능 반사만 예외입니다.

효과 처리 순서는 카드 검증·MP/카드 소비→공격 큐→명중→방어/방향변경→수호자 흡수→HP피해→어둠 즉사/흡수/자해/재앙→부활/사망/유언→질병→수호자→보충/종말위험→최종 승패입니다. 공격자 자신의 카드 사용에 따른 종말 피해는 사용 직후 발생할 수 있고, 이미 생성한 공격은 사망 후에도 남습니다.

## 거래·기적·특수 카드

환전: HP/MP/소지금 총합 보존, 정수0~99, HP는1 이상. 강매는 거래 카드와 실제 판매할 일반 손패를 순서대로 선택합니다. 해당 카드도 소비되고 방어 기회를 거친 뒤 지급·지불됩니다. 상대의 보유 공간이 가득 찼으면 제출 단계에서 거절합니다. 강매·흡수 부족금은 소지금→MP→HP이며 수호자 HP로 지불할 수 없습니다.

BUY는 상대 일반 손패1장을 무작위 선택합니다. 잔액과 보유 공간을 확인한 뒤 구매자에게 가격을 보여 줍니다. 실제 구매 때 소유권·잔액·생존·공간을 재검사합니다. 사망한 구매자/판매자의 확인은 취소합니다. 영구 기적과 FIXED/CREATURE는 거래 대상이 아닙니다. 거래 중 공개되는 것은 실제 제시·사용된 카드이며 상대 전체 손패는 보내지 않습니다.

244는 사망 직전 HP10, 117은 사망 후 빛30/75% 적 전체 유언. 99는 살아 있는 MORTAR 소유자를 찾으면999 방어불가 공격, 없으면 자신을 포함한 임의 대상에게 빛30. 여러 소유자가 있으면 플레이어 저장 순서의 첫 소유자를 선택합니다. MYSTERY의 열 가지 개별 효과는 분석 문서와 카드 명세에 있습니다.

## 재앙

감기1/열병2/지옥병5 피해, 천국병5 회복. 기본은 턴마다5% 악화. 원본 누적 방식은 `diseaseMode` 설정으로 선택합니다. 강한 질병 재부여는 해당 단계로, 같거나 약하면 현재 단계에서 하나 악화됩니다. 천국병에 질병이 다시 들어오면 HP0. 안개·꿈·섬광·먹구름은 중복 저장하지 않습니다.

안개: 자신의 손패 이외 상대 이름·능력치를 가리고, 공격 시 원래 선택한 아군/적군 집합에서 무작위 재지정. 과거에 이미 공개된 정보의 기억까지 제거할 수는 없습니다. 꿈: 새 드로우 때 비기적·비거래 카드의50%를 유사 카드 정보로 보이게 하며 실제 효과는 서버의 원래 ID. 선택 오류도 서버 검증을 통과해야 합니다. 섬광: 방어1장. 먹구름: 확률형 공격 명중 확정.

하위 해제는 감기·열병·안개·섬광만 제거합니다. 전체 해제는 전부 제거하고 꿈 카드의 실제 표시를 복구합니다. 질병 발동 후 사망·부활도 정상 처리합니다.

## 수호자·종말

수호자10종, HP20, 마지막 소환으로 교체. 주인보다 먼저 피해를 받고 초과분을 전달. 적의 행동 종료 후30% 개입. 종류별42개 가중 행동과 EARTH/MOON 특수 생성은 독립 데이터입니다. 수호자의 공격은 카드 소모·주인 MP지출 없이 큐에 들어갑니다. 영구 보유 공간을 차지하지 않습니다.

연습전과 방 생성에서 재앙 시작을 **1·50·100·500턴** 중 선택합니다. 기본100턴이며 플레이어 한 명의 행동을1턴으로 셉니다. 선택은 서버에서 허용 값만 검증하여 방에 저장하고 경기·재대전에 적용합니다. 예전 저장 방에 설정이 없으면100턴으로 시작합니다. 게이지는 현재 턴/시작 턴으로 계산합니다. 이후 카드 사용·보충마다25%로 악마5/10/15 피해 중 하나. 이 선택지와 피해표는 새 게임의 설정이며 원본 확정값이 아닙니다. 여러 카드가 각각 위험 판정을 일으킬 수 있고 사망 시 해당 묶음의 남은 위험 처리는 멈춥니다. FINISHED 이후에는 이벤트를 만들지 않습니다.

## 통신·연결·리플레이

기본60초 인간 입력 제한, 기본650ms AI 지연. 시간 초과·퇴장 후 다른 사람이 남은 경기는 AI 조작으로 이어지고 재참가하면 사람 조작으로 복구합니다. 마지막 사람이 명시적으로 나가면 방을 삭제합니다. 연결 끊김은 마지막 활동부터120초 동안 복귀할 수 있으며, 사람 전원이 이 유예 시간을 넘기면 방을 정리합니다. 대기실의 오래된 좌석은 제거하고 남은 사람에게 방장을 이전합니다. 삭제 조건은 DB 잠금 안에서 다시 검사합니다. 관전자에게도 방 종료를 알립니다.

재접속은 무작위 비밀 토큰으로 인증하며 닉네임으로 인증하지 않습니다. 방이 보존된 동안 저장된 경기·손패·큐·난수·명령을 복원합니다. 관전자는 자기 손패가 없고 게임 명령을 보낼 수 없습니다. 공개 기록은 방이 존재하는 동안 제공하며 삭제 이후의 별도 영구 아카이브는 없습니다.

서버 프로세스가 모두 중단되거나 모든 연결이 없을 때 독립 스케줄러가 돌지는 않습니다. 재접속 시 저장된 마감 시각을 확인해 처리를 재개합니다. 따라서 상시 무인 진행을 보장하는 구조가 아닙니다. 운영 대규모 매치에는 별도 스케줄러·보관 정책·pub/sub 최적화가 필요합니다.

명령 로그와 시드를 서버에만 보존합니다. 공개 기록은 발생 순서의 공개 이벤트만 표시하며, 초기 손패·아직 사용하지 않은 카드·시드·전체 내부 상태는 내보내지 않습니다. 현재 클라이언트는 전투 기록 열람을 제공하고 시간축 재생·관전 리플레이 플레이어는 아직 없습니다.

## 대기실 입장과 경기 대기열

방을 만들거나 입장하면 visitors에 머물며 seats에는 들어가지 않습니다. 개인전(SINGLE) 또는 팀(A/B/C/D)을 누르면 검증 후 대기열에 들어갑니다. 첫 참가자의 선택이 개인전/팀전을 결정하고 이후 서로 다른 종류를 혼합하지 않습니다. 같은 버튼의 중복 입력은 좌석을 늘리지 않습니다. 팀 변경은 준비 상태를 취소합니다. 경기 전 참가 취소는 방 퇴장과 별개이며, 입장자도 채팅·방장 권한·재접속·방 정리 정책에 포함됩니다. 정원2~8명은 실제 대기열에 적용합니다. AI 연습은 즉시 참가/시작 흐름을 유지합니다.

서버는 각 공격·방어·구매 입력 단계의 시작 시각, 기간, 마감 시각을 저장합니다. 클라이언트의 시간 바는 서버 시각 보정 후 남은 시간만 표시합니다. 마감 이후 입력은 거부하고 만료 자동 처리는 DB 잠금 아래 한 번 진행합니다. 클라이언트의 바가0이 되거나 애니메이션이 끝났다는 이유로 경기 상태를 바꾸지 않습니다.
