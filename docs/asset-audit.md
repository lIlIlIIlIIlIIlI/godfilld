## 권리 판단에 사용한 근거

README Remarks는 서버 에뮬레이터만 작성했으며 클라이언트 자료 권리가 원작자 @guuji에게 있다고 설명합니다. `server-src/LICENSE`는 AGPL-3.0이고 client-files 전체에 대한 재배포 허가라고 볼 별도 문구는 확인하지 못했습니다. 허가 증빙이 없으므로 이미지·사운드·SWF·원본 UI를 새 공개 서비스에 넣지 않았습니다. 원작자에게 사용 허가를 받았다고 주장하지 않습니다.

카드 CSV에는 이름과 이미지 URL이 없습니다. 파일명만으로 카드 ID를 대응시키지 않았으며, 그림317개와 데이터364행의 개수 차이를 곧바로 누락47개라고 해석하지 않았습니다. 일반 카드·수호자·재앙·특수 사건 그림이 섞여 있고 weight0 역사 데이터도 있기 때문입니다. Flash 내부 매핑을 완전 역컴파일하지 않아 개별 ID→원본 그림 대응은 **미검증**입니다.

## 신규 리소스와 확장

- 새 한국어 게임명·카드명: 창작 명명. 원작 번역명으로 표시하지 않음.
- 신규 카드 placeholder: `client/public/assets/card-placeholder.svg`, 코드로 작성한 별·원형 문양. 외부 이미지에서 추출하지 않음.
- 아이콘: 설치한 Lucide 라이브러리. 패키지 라이선스는 의존성 배포 시 보존합니다.
- 사운드: Web Audio 사인파로 합성한 효과음과 짧은 반복 음형. 원본 MP3 사용 없음.
- 디자인: 새 아이보리·민트 레이아웃, HTML 카드와 CSS 프레임. 원본 CSS/버튼 이미지 재사용 없음.

`data/asset-manifest.json`은 현재 모든 카드에 신규 placeholder를 지정합니다. 카드 레지스트리의 image URL을 통해 향후 허가받은 리소스를 연결할 수 있습니다. 승인 기록에 권리자·허가 범위·증빙 위치·원본 해시·카드 ID·변환 내역을 함께 남기기 전에는 원본 매핑을 활성화하지 마세요. 외부 이미지 허용 시 CSP와 캐싱 정책도 함께 수정해야 합니다.

현재 SVG는 비율 유지, 이미지 로딩 실패는 기본 그림 또는 아이콘으로 대체합니다. 별도 래스터 그림이 없으므로 WebP 변환은 수행하지 않았습니다. 실제 운영 브라우저 네트워크 캐시·모바일 화질 검수는 추가 대상입니다.
