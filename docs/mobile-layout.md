# 모바일 첨부 사진에 따른 세로 레이아웃

2026-10-18. 사용자 첨부1000032564/2566/2568/2570/2572/2574/2576/2579의8개 PNG를 실제로 열어 확인했습니다. 사진 하단의 삼성 캡처 도구와 작은 캡처 미리보기는 운영체제 UI이므로 게임에 넣지 않습니다. 첨부 이미지는 배포 자산으로 복사하지 않습니다.

## 배치

폭760px 이하 세로 화면에서660 논리 폭을 기준으로 전체 너비에 맞춥니다. PC와 가로 화면은1080×720 배치를 유지합니다. 기존640px 최소 폭과 가로 스크롤은 제거합니다.

논리 좌표를 축소했을 때 작은 터치 버튼은 최소44 CSS px를 유지합니다. 이 경우 사진보다 간격이 늘 수 있으나 버튼과 손패가 겹치지 않도록 상단 전투 영역 높이를 함께 늘립니다.16장 손패와8명 목록을 강제로2줄/2명 영역 안에 자르지 않습니다. 안전 영역을 반영하고 이름 입력 폰트는16px 이상입니다.

## 실제 전투 이벤트

presentation.ts의 표시 큐는 GameView의 신규 공개 이벤트만 받습니다. 실제 HP와 게임 단계는 최신 서버 값을 즉시 사용합니다. 타이머는 카드 판정이나 다음 턴을 기다리게 하지 않고 서버 명령을 만들지 않습니다.

- 처음 시작한 경기의 game_start로 시작 안내를 표시합니다. 진행 중 재접속한 과거 로그는 다시 재생하지 않습니다.
- 방어 전 패널은 서버 current.damage를 예상 피해로 접근성 이름에 표시합니다. 실제 damage 이벤트의 수치는 수호자 흡수 등이 끝난 뒤의 HP 피해입니다.
- demon 이벤트와 뒤따르는 실제 피해를 구분합니다. 다음 일반 공격을 악마 공격으로 잘못 표시하지 않습니다.
- death 이벤트가 있어야 승천을 표시합니다. HP 피해만 보고 사망을 추정하지 않으며 부활에 가짜 승천을 표시하지 않습니다.
- 표시 중에도 서버 상태·승패는 갱신합니다. 신규 이벤트 중복을 제외하고 대기열은8개로 제한합니다. 퇴장/방 종료/재대전 때 이전 타이머와 큐를 정리합니다.
- 종료 표시는 서버 winners를 사용합니다. 새 게임을 시작하거나 경기 끝내기를 누르는 명령도 기존 서버 검증을 거칩니다.

## 원본 악마 그림

공식/i18n/ko.json의 실제 items 정의와 이미지 경로 생성 코드를 확인한 뒤 items/devils/small-devil.webp, medium-devil.webp, large-devil.webp를 받았습니다. 실제 그림도 열어 첨부 사진의 소악마·중악마와 대응을 확인했습니다. 원본 정의의 피해10/20/30에만 해당 그림·이름을 대응합니다.

기존 게임 엔진 기본 피해표5/10/15를 원본 수치로 바꾸지는 않았습니다. 해당하는 그림이 없는 수치는 일반 악마와 기본 이미지를 사용하며 임의로 소악마/중악마 이름을 확정하지 않습니다. 출처·바이트·SHA256은 data/ui-asset-manifest.json에 있습니다. 이전에 사용자가 확인한 원본 미디어 사용 허가에 따라 포함하며 코드의 AGPL과 미디어 권리를 구분합니다.

## 검증 범위

자동 검사398개와 타입 검사·운영 빌드를 실행했습니다. DOM 검사에서 실제 엔진의 공격→용서하기→피해→사망→승리→경기 끝내기, 카드 메뉴/기적 목록을 확인합니다. 별도 큐 검사는 표시 순서·중복·흡수·재접속·재대전·퇴장·서버 데이터 불변·표시 대기 상한을 검사합니다. 원본 화면 자산9개는 바이트 크기와 SHA256을 검사합니다.

브라우저 제어 환경이 없어 실브라우저 스크린샷 비교·실기기 터치·가로세로 회전 QA는 미실시입니다. DOM 검사와 CSS 구현을 실기기 픽셀 검증으로 표시하지 않습니다. 운영 WebSocket 전체 대전 검증의 기존 한계도 그대로입니다.

## 대기열 및 시간 바 보완

방 입장은 경기 참가가 아닙니다. 처음에는 대기열이 비어 있으며 개인전/팀 선택 후에만 중앙 슬롯에 표시합니다. 실제 입장자는 하단 명단에 표시합니다. 전투의 기존 장식 구분선을 행동 제한 시간 바로 바꿨고 세로 모바일에서도 손패 바로 위에 표시합니다. 서버의 마감 시각을 사용하며 클라이언트에서 시간을 줄여 서버에 만료 명령을 보내지 않습니다. 기본60초, 마지막20초 빨간색, 만료 시 서버 자동 진행입니다. G.F. 종말 수치와 별도입니다.
